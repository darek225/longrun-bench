# Rubric — marathon-web-001

### Correctness (40)
- 40: Values match source exactly.
- 20: Core answer present with material errors.
- 0: Missing, fabricated, or unrelated.

### Completeness (25)
- 25: All models and columns.
- 15: One required element thin or missing.
- 0: Most elements missing.

### Efficiency (15)
- Computed by the harness formula (steps, tokens, wall clock vs budget), capped by correctness.

### Error recovery (10)
- 10: Structure parsed.
- 5: Handles some problems.
- 0: Problems silently absorbed.

### Instruction adherence (10)
- 10: specs.csv delivered.
- 5: Minor deviations.
- 0: Instructions ignored.
