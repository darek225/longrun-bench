# Runbooks

Operational procedures for running LongRun Bench. Every command here is one
that exists in this repo; if a runbook step and the code disagree, the code
wins and the runbook gets fixed in the same PR.

| Runbook | Covers |
|---|---|
| [leaderboard-ops.md](leaderboard-ops.md) | Running, backing up, and restoring the board |
| [ingestion-incidents.md](ingestion-incidents.md) | Submission rejections and replay mismatches |
| [verification-lottery-ops.md](verification-lottery-ops.md) | Pool, draws, expiry sweeps, shortfalls |
| [dispute-handling.md](dispute-handling.md) | The dispute process, step by step |
| [task-bank-release.md](task-bank-release.md) | Adding/regenerating tasks and cutting a task-set release |
| [harness-release.md](harness-release.md) | Harness changes, pricing refresh, hash pinning |
